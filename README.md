# پولکی (Pulaki) — نسخه اول

اپلیکیشن مدیریت هزینه‌های شخصی، ساخته‌شده با Kotlin + Jetpack Compose + Room (کاملاً آفلاین).

## چی توی این نسخه هست (v1 ساده)

1. ✅ ثبت تراکنش سریع با Bottom Sheet (مبلغ، نوع هزینه/درآمد، دسته، حساب، یادداشت)
2. ✅ دسته‌بندی از پیش‌ساخته برای هزینه و درآمد (قابل توسعه در دیتابیس)
3. ✅ چند حساب (پیش‌فرض: نقدی + کارت بانکی) با محاسبه خودکار مانده هر حساب
4. ✅ بودجه‌بندی ماهانه ساده: تعیین سقف برای هر دسته + نوار پیشرفت و هشدار نزدیک/اتمام بودجه
5. ✅ خلاصه دخل‌وخرج در صفحه اصلی (مانده کل، جمع درآمد، جمع هزینه)
6. ✅ جستجوی تراکنش بر اساس یادداشت یا نام دسته
7. ✅ حالت آفلاین کامل (همه‌چیز روی دیتابیس محلی Room ذخیره می‌شه)
8. ✅ تم تیره پیش‌فرض با رنگ سبز/فیروزه‌ای (اصلی) و قرمز/صورتی (هزینه/هشدار)، کارت‌های گردگوشه
9. ✅ خواندن خودکار پیامک بانکی (فقط اندروید) — جزئیات زیر

### خواندن خودکار پیامک بانکی چطور کار می‌کنه

- با اجرای اول اپ، مجوز `RECEIVE_SMS` درخواست می‌شه (اگه رد بشه، بقیه اپ عادی کار می‌کنه، فقط این قابلیت غیرفعال می‌مونه).
- یک `BroadcastReceiver` (فایل `sms/SmsReceiver.kt`) به پیامک‌های دریافتی گوش می‌ده.
- یک parser ساده (`sms/BankSmsParser.kt`) با استفاده از کلیدواژه‌هایی مثل «برداشت»، «خرید»، «واریز» و یک regex برای عدد + واحد (ریال/تومان) تشخیص می‌ده که پیامک تراکنش بانکیه یا نه، مبلغ چقدره و هزینه‌ست یا درآمد.
- تراکنش تشخیص داده‌شده به‌صورت «پیشنهاد» (`SmsSuggestion`) در دیتابیس ذخیره می‌شه، نه مستقیم به‌عنوان تراکنش نهایی.
- توی اپ یک دیالوگ تأیید باز می‌شه که مبلغ و نوع تراکنش رو نشون می‌ده و از کاربر می‌خواد دسته و حساب رو انتخاب کنه؛ بعد از تأیید، تراکنش واقعی ثبت می‌شه.

**نکته مهم:** فرمت پیامک بانک‌ها بین بانک‌های مختلف ایرانی فرق می‌کنه. فعلاً الگوها برای **بلو بانک** و **بانک ملی** با نمونه پیامک واقعی تنظیم شدن (شامل برداشت، واریز، انتقال، و تشخیص/نادیده‌گرفتن پیامک رمز پویا که تراکنش نهایی نیست). اگه از بانک دیگه‌ای هم استفاده می‌کنی، چند نمونه پیامک بفرست تا الگوی اون بانک هم اضافه بشه.

## چیزهایی که هنوز پیاده نشده (برای فازهای بعدی)

این‌ها امکانات پیشرفته‌تری هستن که بهتره در نسخه‌های بعدی و بعد از تست نسخه اول اضافه بشن:

- ساخت دسته/زیردسته با انتخاب آیکون از UI (فعلاً دسته‌ها در دیتابیس seed می‌شن، ولی افزودن با آیکون دلخواه از داخل اپ نیاز به یک فرم جدا داره)
- نمودار و گزارش مقایسه‌ای با ماه قبل (نیاز به کتابخونه چارت مثل Vico یا MPAndroidChart)
- مدیریت دارایی غیرنقدی (طلا/دلار/ارز دیجیتال) با قیمت لحظه‌ای
- طلب و بدهی با اشخاص
- یادآور چک/قسط (نیاز به AlarmManager/WorkManager)
- پشتیبان‌گیری ابری (Dropbox API یا سرور اختصاصی)
- خروجی اکسل
- اشتراک پولکی‌پلاس (نیاز به Google Play Billing)

## گرفتن فایل APK از طریق گیت‌هاب (بدون نیاز به build لوکال)

اگه Android Studio روت مشکل sync داره (مشکل شبکه/دسترسی به ریپازیتوری‌های گوگل)، ساده‌ترین راه اینه که بذاری خود گیت‌هاب پروژه رو build کنه:

1. پروژه رو push کن به یه ریپازیتوری گیت‌هاب (اگه از قبل git init و commit اول رو زدی، فقط کافیه remote اضافه کنی و push کنی — به پیام قبلی مراجعه کن).
2. توی گیت‌هاب برو به تب **Actions** ریپازیتوری. یه Workflow به اسم **Build APK** می‌بینی (فایلش `.github/workflows/build.yml` هست).
3. اگه خودش اجرا نشد، دستی روی **Run workflow** بزن.
4. صبر کن (چند دقیقه طول می‌کشه). وقتی سبز شد، روی همون run کلیک کن؛ پایین صفحه یه بخش **Artifacts** هست با اسم `pulaki-debug-apk` — دانلودش کن.
5. فایل zip دانلودی رو باز کن، `app-debug.apk` رو بگیر و روی گوشی اندرویدت منتقل کن (یا با لینک دانلود مستقیم روی خود گوشی باز کن).
6. موقع نصب، اندروید ممکنه بگه «نصب از منابع ناشناس» — اجازه بده (چون از گوگل‌پلی نیست، عادیه برای اپ debug).

این روش کاملاً روی سرورهای گیت‌هاب build می‌شه، پس مشکل شبکه/فایروال سیستم خودت اصلاً دخیل نیست.

## راه‌اندازی لوکال (Android Studio)

1. [Android Studio](https://developer.android.com/studio) (نسخه Koala یا جدیدتر) رو نصب کن.
2. پوشه `PulakiApp` رو با Android Studio باز کن (Open an existing project).
3. صبر کن Gradle sync تموم بشه (نیاز به اینترنت برای دانلود dependency‌ها داره).
4. روی Run بزن یا از یک دستگاه/شبیه‌ساز اندروید ۸ به بالا (API 26+) استفاده کن.

## ساختار پروژه

```
app/src/main/java/com/polaki/expense/
├── data/              # Entity ها، DAO ها، Room Database
├── ui/theme/          # رنگ‌ها، تایپوگرافی، شکل‌ها (تم تیره)
├── ui/components/     # AddTransactionSheet، TransactionRow
├── ui/screens/        # HomeScreen، BudgetScreen، AccountsScreen
├── util/Format.kt     # فرمت اعداد فارسی و تومان
├── MainActivity.kt    # Scaffold + Navigation Bar + FAB وسط
└── PulakiViewModel.kt # منطق و state اپ
```

هر وقت خواستی یکی از قابلیت‌های فاز بعدی رو اضافه کنیم بگو تا روش کار کنیم.
